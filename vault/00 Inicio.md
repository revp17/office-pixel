# Office-Pixel — Mapa del vault

Simulador visual de procesos para Forward Deployed Engineers (FDE): el FDE define un proceso (etapas, reglas, excepciones, tiempos), lo simula y lo observa avanzar en un mapa 2D pixel-art transitable.
