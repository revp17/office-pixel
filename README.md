# Office-Pixel

Simulador visual de procesos para Forward Deployed Engineers: define un proceso (etapas, reglas, excepciones, tiempos), simúlalo y obsérvalo avanzar en un mapa 2D pixel-art.

- `vault/` — vault de Obsidian con el diseño del producto (abre esa carpeta en Obsidian; empieza por `00 Inicio.md`).
- Código del prototipo: pendiente (ver `vault/13 Roadmap del prototipo.md`).
